# Markdown Note Taker
This application allows users to write and preview markdown notes stored locally in the browser.

## Description
The application listens for input events on the textarea, immediately parsing the markdown text into formatted HTML and rendering it in the preview pane. All note data is serialized and saved to browser local storage whenever changes occur.

## Capabilities
- Live markdown preview
- Local storage persistence
- Search and filter notes
- Export all notes to JSON

## Structure
- `index.html`: Main markup structure and layout
- `style.css`: Styles conforming to the design guide
- `script.js`: Application logic and markdown parser

## Execution
Open `index.html` in a browser. No install or build step.
